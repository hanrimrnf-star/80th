# 학생신앙운동 SFC 80주년 기념행사

1947 – 2027 · Ad fontes, missions come true (본질을 회복하자, 사명을 성취하자)

SFC 80주년 기념행사를 안내하는 모바일 한 페이지 웹사이트입니다.

- 페이지 주소: https://80th.sfc.or.kr/
- 내용 출처: SFC 80주년 기념 브로슈어

## 구성

- `index.html`: 페이지 전체 (스타일과 스크립트 포함)
- `fonts/`: G마켓산스, 페이퍼로지, 나눔펜(부분), 나눔명조(부분)
- `img/`: 브로슈어에서 가져온 사진과 포스터, 공유용 이미지(`og.jpg`)

## 수정할 때

- 문의 연락처: `index.html`의 문의 섹션에 있는 "연락처 입력 필요" 표시를 실제 연락처로 바꿔 주세요.
- 손글씨(나눔펜)와 명조 글꼴은 페이지에 쓰인 글자만 담은 파일입니다. 해당 글꼴로 새 글자를 넣으면 그 글자는 기본 글꼴로 보일 수 있습니다.
